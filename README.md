# 📌 Sistema de Cadastro de Pessoas (CRUD em Java)

## 📖 Sobre o Projeto

Este projeto é um sistema simples de cadastro de pessoas desenvolvido em Java, com o objetivo de praticar conceitos fundamentais de programação, orientação a objetos e estruturação de código.

O sistema permite realizar operações básicas de um CRUD:

* ✅ Cadastrar pessoas
* 📋 Listar pessoas
* ✏️ Editar dados
* ❌ Remover registros

---

## 🚀 Tecnologias Utilizadas

* Java
* Programação Orientada a Objetos (POO)
* Estrutura de listas com ArrayList
* Entrada de dados com Scanner

---

## 🧠 Conceitos Aplicados

* Encapsulamento
* Classes e Objetos
* Listas dinâmicas
* Separação de responsabilidades (Model / Service)
* Estrutura de repetição e controle de fluxo

---

## ▶️ Como Executar o Projeto

1. Clone o repositório:

git clone https://github.com/RonaldNerys/person-registration-system.git

2. Abra o projeto em uma IDE (IntelliJ IDEA recomendado)

3. Execute o arquivo:
   Main.java

4. Utilize o menu no terminal para interagir com o sistema
